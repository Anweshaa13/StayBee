# 📖 About StayBee

StayBee is a full-stack vacation rental web application inspired by Airbnb. It enables users to explore unique stays, list their own properties, save favourite destinations, book accommodations, and securely manage their reservations.

The project follows the MVC architecture and includes secure authentication, image uploads, payment integration, cloud storage, and responsive design.

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Anweshaa13/StayBee.git
```

### Navigate into the Project

```bash
cd StayBee
```

### Install Dependencies

```bash
npm install
```

### Create a `.env` File

Create a `.env` file in the project root and add the following environment variables with your own credentials:

```env
ATLASDB_URL=

SECRET=

CLOUD_NAME=
CLOUD_API_KEY=
CLOUD_API_SECRET=

MAPTILER_API_KEY=

RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
```

### Run the Application

```bash
npm start
```

### Run the Application

```bash
npm start
```

The application will be available at:

```
http://localhost:8080
```
